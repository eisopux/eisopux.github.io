## EISOP User Experience

The [Enforcing, Inferring, and Synthesizing Optional Properties (EISOP) Framework](https://eisop.github.io/) project
aims to provide a unified framework for optional properties in Java.

This site indexes the EISOPUX projects: IDE and editor integrations, and other tooling, that make
the EISOP Checker Framework easier to use day to day. See also the
[eisopux GitHub organization profile](https://github.com/eisopux/.github/blob/main/profile/README.md)
for a shorter version of this list.

## IDE Integrations

- [Checker Framework Language Server](https://github.com/eisopux/checker-framework-languageserver) --
  a Language Server Protocol (LSP) server that runs the Checker Framework and reports its findings
  to any LSP-compatible editor.
- [Checker Framework LSP Downloader](https://github.com/eisopux/checker-framework-languageserver-downloader) --
  downloads and installs the Language Server for editor extensions that bundle it.
- [Checker Framework VS Code Extension](https://github.com/eisopux/checker-framework-vscode) --
  Visual Studio Code support for the Checker Framework, built on the Language Server.
- [Checker Framework instructions for IntelliJ IDEA](https://github.com/eisopux/checker-framework-idea) --
  how to run the Checker Framework from IntelliJ IDEA.
- [Checker Framework Support for Eclipse](https://github.com/eisopux/checker-framework-eclipse) --
  Eclipse integration for the Checker Framework.
- [Checker Framework Theia Plugin Example](https://github.com/eisopux/checker-framework-theia) --
  an example Theia IDE plugin built on the Language Server.


## Additional Tooling

- [Javac Diagnostics Wrapper](https://github.com/eisopux/javac-diagnostics-wrapper) --
  post-processes javac and Checker Framework diagnostics into other formats, such as JSON, LSP,
  or SARIF.
